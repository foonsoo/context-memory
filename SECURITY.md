# Security policy

Context Memory's supported product is a local plaintext SQLite database and MCP
server. Processes running as the same OS user and copies in backups are within
the trust boundary. Do not store secrets. Hosted code in this repository is a
prototype, not an offered service.

Do not open a public issue containing a real memory database, personal data,
credentials, private paths, or unredacted logs. GitHub private vulnerability
reporting has not been verified as enabled for this repository. If no private
reporting option is visible, publish only a redacted notice that maintainers need
to arrange a private channel; do not include exploit details or sensitive data.

No maintainer response time, security-support window, or private contact address
is promised here. Enabling and documenting a verified private reporting channel
remains a repository-administrator task.
